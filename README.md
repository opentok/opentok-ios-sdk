# OpenTok iOS SDK

The OpenTok iOS SDK lets you use OpenTok-powered video sessions in apps you build for iPad, iPhone, and Mac devices.

For full documentation, installation instructions, system requirements, and guides, visit the **[OpenTok iOS SDK overview](https://developer.vonage.com/en/opentok/sdks/ios/overview)** on the OpenTok developer portal.

## Installation

Add the SDK to your project using Swift Package Manager:

```
https://github.com/opentok/opentok-ios-sdk.git
```

In Xcode, go to **File > Add Package Dependencies…**, paste the URL above, and select the **OpenTokClientSDKVideo** library.

> For full installation instructions (including CocoaPods and migration from CocoaPods), see the [Installation section](https://developer.vonage.com/en/opentok/sdks/ios/overview#installation) of the developer portal.
